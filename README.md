# World News — 18 November 2026, in One Image

make.fun bounty submission: **"Sum up 18 November's world news in one image"**
($250, no entry fee, deadline Fri 20 Nov 2026 07:00 WIB).

## What it does

`main.py` renders a single 1600×1160 PNG infographic — **WORLD NEWS,
Wednesday, 18 November 2026** — with the six stories that shaped the day
plus an "Also today" strip:

1. **US–Iran war escalates** — US sinks five Iranian tankers; Iran
   strikes ships near Hormuz and missiles at a US base in Jordan.
2. **Ukraine hits Kerch Bridge again** — second night of strikes on the
   Crimea link as Russia hits bridges ahead of Thursday's summit.
3. **Gaza faces a freezing winter** — UN warns of more deaths from cold;
   1.7M displaced, 1.4M face acute hunger.
4. **COP31 talks enter final days** — 144 disputed items in Antalya
   before the summit ends Friday.
5. **Trump lands in Manila for Quad** — Quad talks ahead of a China
   visit; a would-be assassin is jailed for 27 years.
6. **Pattinson is the new James Bond** — Robert Pattinson named the
   next 007.

Also today: North Korea missile launch, 5.3 quake in Romania, Waymo
pulls robotaxis from US freeways, US measles cases at a 40-year high,
Eisenkot tapped to lead Israel.

Sources: wire reports and major outlets, 18 November 2026.

## How to run

```sh
python3 main.py
```

Writes the image to `/output/entry.png` (and to `output/entry.png`
next to the script as a fallback).

## Constraints honoured

- **Python 3.13, standard library only** — imports are `os`, `struct`,
  `zlib`. No third-party packages, no network access.
- **Deterministic** — same run produces byte-identical PNG every time
  (verified: two consecutive runs give the same SHA-256).
- **One image** — a single PNG at `/output/entry.png`.
- The PNG is encoded with a hand-written encoder and a built-in 5×7
  bitmap font (no font files, no image libraries at runtime).

## Files

- `main.py` — the whole program (renderer + content + PNG encoder).
- `TRANSCRIPT.md` — session transcript of the agent run that built it,
  including the full source of `main.py`.
- `output/entry.png` — the rendered image (regenerated by `main.py`).
